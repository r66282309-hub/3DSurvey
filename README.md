# WebGIS 3D Supabase + Leaflet

Mini-app statica per:
- leggere punti da Supabase;
- visualizzarli su mappa Leaflet con basemap Esri;
- mostrare punti arancioni circolari;
- aprire popup con informazioni;
- aprire un viewer GLB/3D tramite pulsante "Visualizza punto AR";
- inserire punti da un survey web.

## File principali

- `index.html` = WebGIS
- `survey.html` = form inserimento punti
- `viewer.html` = visualizzatore GLB
- `config.js` = chiavi Supabase e nome tabella
- `models/` = cartella dove caricare i file `.glb`

## Configurazione

Apri `config.js` e inserisci:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "xxxxx",
  TABLE_NAME: "punti_3d",
  MODEL_BASE_PATH: ""
};
```

Usa solo la chiave `anon public`, mai la `service_role`.

## Tabella Supabase consigliata

```sql
create table if not exists punti_3d (
  id bigint generated by default as identity primary key,
  nome text not null,
  descrizione text,
  lat double precision not null,
  lon double precision not null,
  modello_glb text,
  foto_url text,
  data_rilievo date,
  note text,
  created_at timestamp with time zone default now()
);
```

## RLS di esempio

Per test rapidi, puoi abilitare una policy pubblica. Per un progetto reale conviene aggiungere autenticazione.

```sql
alter table punti_3d enable row level security;

create policy "public read punti_3d"
on punti_3d
for select
to anon
using (true);

create policy "public insert punti_3d"
on punti_3d
for insert
to anon
with check (true);
```

## Uso dei modelli 3D

1. Esporta da Scaniverse in `.glb`.
2. Copia il file in `models/`, per esempio:
   - `models/aula_grande.glb`
   - `models/stanza1.glb`
   - `models/crepa.glb`
3. Nel survey, nel campo "Percorso o URL modello GLB", scrivi:
   - `models/aula_grande.glb`

Il survey non carica direttamente file su GitHub. Salva solo il percorso del file GLB.

## Pubblicazione GitHub Pages

1. Crea repository GitHub.
2. Carica tutti i file.
3. Vai su Settings → Pages.
4. Source: Deploy from branch.
5. Branch: `main` / root.
6. Apri l'URL generato da GitHub Pages.

## Nota sui GLB

GitHub blocca file singoli oltre 100 MB. Per il web conviene comunque tenere i GLB sotto 20-50 MB.
